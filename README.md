# ML Course

Notes, assignments, and code for my introductory machine learning course.

Course textbook: *Machine Learning – A First Course for Engineers and Scientists* (Lindholm, Wahlström, Lindsten, Schön).

## Structure

- `notebooks/` — exploration and worked examples
- `assignments/` — problem sets and solutions
- `data/` — datasets (small ones only; anything large should be `.gitignore`d)
- `src/` — reusable helper code (data loading, plotting, models)

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
